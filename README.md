# Açıklama:
NodeMCU Lolin ESP8266 V3 kartında güç verildiği anda otomatik olarak açık ve şifresiz bir Wi-Fi ağı yayınlayan küçük bir şaka projesi. Ağa bağlanan cihazlar "İnternet olmadan bağlı" uyarısı alır, hepsi bu.

# Gerekenler:
NodeMCU Lolin ESP8266 V3 kartı
Veri destekli bir micro-USB kablosu (sadece şarj kablosu olmaz)
CH340 sürücüsü (Lolin V3 kartlarda genelde CH340 çipi bulunur. Kart USB'de görünmüyorsa "CH340 driver" aratıp kur)

# Kullanım:
1. Arduino IDE'yi aç.
2. Bu kodunu temiz bir sayfaya yapıştır.
3. NodeMCU kartını bilgisayara bağla.
4. Sol üstteki Yükle (Ok işareti) butonuna bas

- veya başka program kullan, yapman gerekenler programa göre değişir.

Bu proje sadece eğlence amaçlıdır. Gerçek ağ isimlerini (operatör, kafe, okul, iş yeri vb.) taklit etme. Karışıklığa yol açabilir ve istenmeyen sonuçlar doğurabilir.
